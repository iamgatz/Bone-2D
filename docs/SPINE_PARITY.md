# Spine и Bone 2D: функция за функцией

Список функций Spine взят из его документации (esotericsoftware.com/spine-user-guide и страницы видов, прочитаны 2026-11-19), а не по памяти. Наша колонка сверена с кодом.
Метки: ✅ есть · 🟡 есть частично · ❌ нет · ⛔ не делаем (причина в строке). Пробелы из этой таблицы закрыты в версии 0.53 (см. «Остаётся» внизу).

Сравниваются редактор и данные. Рантаймов для игровых движков у нас нет: экспорт загружается официальными рантаймами Spine.

Контрольные точки, Tween, зеркальная поза, вращение вокруг точки, слои, плавная смена картинок, страница-плеер, метки, Wiggle, цепочки физики, пресеты констрейнтов, опорное видео, живое сравнение поз, нарезка спрайт-листов и GIF.

## Остаётся

Всё, что в таблице выше помечено ❌ или 🟡, и ничего сверх этого. Главное по пользе для аниматора:

- Ghosting по ключевым кадрам, со смещением и режимами Silhouette / Xray (M).
- Preview с несколькими живыми дорожками (alpha, additive, hold previous) (M).
- Graph: Store / Swap, режимы Blend / Shift / Average для Favor, перетаскивание края выделения для масштаба времени (M).
- Закрепление скинов (Pins), параметры дубликата скина, история выделения (S).
- Outline view (миникарта позы), Pixel snap, настройки Pixel grid / Show FPS (S).
- «Найти и заменить» по выделению и по текущему скину, переименование картинок (S).

Не делаем: полигональная упаковка атласа, ninepatch, JPG-страницы, форматы PSD / AVI / MOV, импорт `.spine`, скрипты внешних редакторов, Minimal / JavaScript JSON.
