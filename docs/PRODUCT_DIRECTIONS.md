## Рейтинг идей

1. **Обратная связь по анимации без сервера и без аккаунтов (делаем, v0.58).** Страница-плеер (один HTML-файл, открывается где угодно) получает кнопку «Комментарий»: рецензент ставит замечание на момент анимации (с именем) и скачивает файл замечаний; аниматор импортирует его, и замечания становятся маркерами таймлайна с автором, с отметкой «решено». Польза: закрывает самую частую подтверждённую боль (комментарии и согласование), нужен только файл. Отличие: у Spine такого нет и просят, у Rive «планируется». Цена: M. Риск: файл замечаний приходит снаружи, поэтому разбор строгий (лимиты, типы, идемпотентный повторный импорт). Проверяемость: тесты разбора и применения, враждебный ввод, фаззер.
2. **Сравнение двух версий проекта по смыслу (кости, ключи, констрейнты), а не по тексту файла.** Боль: шумный формат мешает слиянию. У нас уже есть контрольные точки со сравнением внутри сессии; нужно сравнение двух файлов. Польза высокая, цена M–L, риск: сопоставление по id хрупко, если файлы разошлись давно. Следующий кандидат после п. 1.
3. **Отчёт «чем отличается от движка» в окне экспорта**: список типичных причин расхождений (режим альфы PMA, версия рантайма, IK / clipping) под выбранные настройки. Боль подтверждена, цена S. Польза скромнее, чем у п. 1–2.
4. **Живая совместная правка (несколько человек одновременно).** Отвергнуто сейчас: нужен сервер сигналов и слияние правок (CRDT); у нас статический хостинг; проверить правильность слияния нечем, а риск испортить чужой проект высок. Вернёмся, если понадобится именно живое присутствие, а не обратная связь.
5. **Автоматический риггинг / веса «одной кнопкой».** Отвергнуто: качество не проверить тестами, а плохой авто-результат хуже ручного.
6. **Предпросмотр на телефоне по QR-коду.** Отвергнуто сейчас: без сервера-посредника нужен прямой канал между устройствами (WebRTC), то есть тот же сервер сигналов; для просмотра на телефоне уже есть страница-плеер как файл.
