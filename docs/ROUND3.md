# Bone 2D — раунд 3: «формат умеет — редактор не умеет»

> Третий самопромпт. Пользователь спросил «что дальше?» — решение принял я сам (как и в раунде 2).

## 0. Решение

В JSON 4.3 есть вещи, которые Bone 2D уже хранит/экспортирует, но **не может создать, показать или анимировать**:

| Что | Состояние до раунда 3 |
|---|---|
| clipping / bounding box / point аттачменты | нет совсем (импорт их пропускал с предупреждением) |
| two-color tint (`dark`, `rgba2` / `rgb2`) | поле `dark` хранится и экспортируется, но нет UI, нет рендера, нет ключей, импорт теряет анимацию |
| ключи transform-миксов | данные и экспорт есть, в таймлайне UI нет |

Все три — то, чем пользуются в каждом реальном проекте (маски, хитбоксы, «вспышка при ударе», точки спавна).
Берусь за них в таком порядке: **A** аттачменты → **B** two-color → **C** transform-миксы → **D** документы.
Не берусь (осознанно): path/physics, импорт 4.0–4.2, `.skel`, onion skin, веса/деформации для полигонов.

## 1. Самопромпт

Ты — инженер, который довёл Bone 2D до «проверено против официального рантайма» и теперь расширяет его, не теряя
этого свойства. Правила (те же, что в раунде 2, плюс два):

1. Формат и семантика — только из исходников `node_modules/@esotericsoftware/spine-core` 4.3.13. Никаких догадок «по памяти».
   **Файлы dist заканчиваются огромной inline-sourcemap: читать только с `limit`, не доходя до последней строки.**
2. Любая новая сущность = (модель → валидатор → солвер/рантайм → экспорт → импорт → дифф-тест → UI → операция в fuzz-наборе).
   Сущность без fuzz-операции не считается законченной: fuzz находит «висячие ссылки» быстрее любого ревью.
3. Любой рендер-эффект проверяется глазами в браузере (скриншот), логика — тестом. «Выглядит правильно» без обоих не считается.
4. Вертикальные срезы: `tsc --noEmit` → `vitest run` → проверка в браузере после каждого.
5. Не раздувать: веса/деформации для полигонов, path, physics — не делаю; данные импортируемых файлов сохраняю и честно предупреждаю.
6. Фоновые задачи не поллить. В финале — честный отчёт: что сделано, чем проверено, что нет.

## 2. Семантика (из официального рантайма)

- **Clipping** (`SkeletonClipping`, `SkeletonRendererCore`): в цикле по draw order для каждого слота:
  нет attachment / слот неактивен / alpha 0 (кроме clipping) → `clipEnd(slot)`; clipping-слот → `clipEnd(slot)`, затем `clipStart`
  (игнорируется, если клип уже идёт); обычный слот → рисуется **с клипом**, после него `clipEnd(slot)`.
  `clipEnd(slot)` завершает клип только если `endSlot === slot.data` → **конечный слот клипуется включительно**;
  `end = null` → до конца кадра. `inverse` — виден только внешний мир, всегда выпуклый; `convex` — полигон трактуется
  выпуклым (если деформирован в вогнутый — берётся выпуклая оболочка).
- **Bounding box**: `SkeletonBounds.update` собирает полигоны всех слотов, чей *применённый* attachment — bounding box;
  `containsPoint` — чётно-нечётный тест.
- **Point**: `computeWorldPosition = (x·a + y·b + worldX, x·c + y·d + worldY)`, `computeWorldRotation = atan2Deg(...)`.
- JSON: `clipping{end(имя слота),convex,inverse,vertexCount,vertices,color}`, `boundingbox{vertexCount,vertices,color}`,
  `point{x,y,rotation,color}`; вершины как у меша (взвешенные = `[n,(bone,x,y,w)*]`, признак — длина массива ≠ `2·vertexCount`).
- **Two-color**: `rgba2 {light,dark}` / `rgb2 {light,dark}`; dark зажимается в 0..1; в setup у слота должен быть `dark`
  (иначе у официального рантайма `darkColor == null`).

## 4. Статус на конец сессии (лимит использования исчерпан)

**Сделано — часть A целиком** (clipping / bounding box / point): модель, валидатор, рантайм-данные, экспорт/импорт, дифф-тест против официального рантайма

в рендерере, инструменты `C` / `X` / `P`, правка вершин, инспектор, оверлей, операции в fuzz-наборе (+ сверка полигонов и точек с официальным рантаймом).
Проверка: `tsc` чисто, 113 тестов, fuzz 400 × 100 (seeds 1–400) зелёный, браузер (клиппинг обычный и inverse, создание / правка / undo).

**Найдено руками и исправлено:** `SlotInspector` вызывал хук после раннего `return` → React падал («Rendered fewer hooks»), когда undo удалял выбранный слот
(воспроизводилось и для «добавить картинку → Ctrl+Z»). Добавлен `sanitizeSelection()` (подписка в `App.tsx`) и инвариант в fuzz-наборе.

**Не начато:** B (two-color tint: рендер, инспектор, ключи `rgba2` / `rgb2`, экспорт, импорт) и C (ключи transform-миксов в таймлайне).
Заметки для B: официальная семантика прочитана (`RGBA2Timeline` / `RGB2Timeline` в `Animation.js`): dark зажимается в 0..1, у слота в setup должен быть `dark`;
план модели — `SlotTimelines.rgba2` (7 каналов `[r,g,b,a,dr,dg,db]`); формула шейдера для straight alpha — `rgb = tex.rgb*light.rgb + (1-tex.rgb)*dark.rgb`,
`a = tex.a*light.a`; код анимации слотов — `src/core/animate.ts` (две ветки `rgba`: основная и «от текущего» для слайдеров).

**Не проверено:** реальной мышью (инструменты проверены синтетическими pointer-событиями); открытие экспортированного `preview.html` с clipping;
длинный fuzz (seeds 1000–1299 × 110) был запущен в фоне — результат не просмотрен.

- Веса и деформации для bounding box / clipping (данные импортируемых файлов сохраняются и рисуются, правка — только перенос вершин).
