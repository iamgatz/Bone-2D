# Идеи на потом

Откуда: дорожная карта Spine (esotericsoftware.com/spine-roadmap, список «Enhancements», прочитан 2026-11-17: в нём 194 пункта, ничего не запланировано поимённо) и форум Spine.
Сюда попадает только то, что реально пригодится аниматору. Каждая строка: что, почему, оценка (S — часы, M — день, L — несколько дней).

## Просят пользователи Spine, у Spine нет

| Идея | Зачем | Размер |
|---|---|---|
| Маркеры и заметки на таймлайне (имя + цвет + текст) | в Spine просят годами; для ритма, синхронизации со звуком и комментариев команде | M |
| Синхронизировать первый и последний ключ для петли | самая частая рутина цикличных анимаций (ходьба, idle) | S |
| Solo slot (показать только выбранный слот) | отладка слоёв и мешей | S |
| Скрыть всё кроме выбранного / показать всё | то же в дереве; отдельно от Ctrl+H | S |
| Скрыть кости без ключей в текущей анимации | в большом риге видно только то, что анимируется | S |
| Mute таймлайна (не играть дорожку, не удаляя) | сравнить «с» и «без» | S |
| Выбрать все ключи одной дорожки | сейчас только рамкой | S |
| Zoom to selected / zoom to loop range | быстрая навигация | S |
| Пресеты констрейнтов (сохранить настройки физики/IK под именем) | физику подбирают долго, потом копируют | M |
| Сохранение раскладок окон под именем (Setup, Animate, Mesh) | просят, у Spine только одна раскладка | S |
| Линейки и направляющие | позиционирование, у Spine в списке | M |
| Подтверждение перед перезаписью экспорта; показ пути в диалоге | теряют файлы | S |
| Кнопка «копировать настройки экспорта» (как JSON) | передать коллеге | S |
| Сохранять кривую, если вставленный ключ совпадает по значению | иначе вставка ломает ручные кривые | S |
| Soft selection для вершин меша и clipping-полигонов | двигать вершины плавным спадом | M |
| Цвет вершин, смещение UV текстуры меша | просят для шейдерных эффектов | L |
| Кисть весов нелинейная, форма и сила | аккуратная раскраска весов | M |
| Автовеса по расстоянию до кости | быстрее ручной раскраски | M |
| Предпросмотр сочетаний скинов | у Spine только по одному | M |
| Ghosting из других анимаций | сравнить кадр с другой анимацией | M |
| Фейд вложений при смене слота (кроссфейд) | просят для мимики | M |

## Наши идеи (animator-first)

| Идея | Зачем | Размер |
|---|---|---|
| Проверка скольжения стопы (foot-slide) | ноги скользят по земле: показать, на каких кадрах | M |
| Авто-зеркало цикла (шаг левой → правой) | половина работы над ходьбой | M |
| Опорное видео под вьюпортом (reference) | ротоскоп, синхрон с таймлайном | M |
| Wiggle / шум на дорожке | живая «дрожь» без ручных ключей | M |
| Аддитивные слои анимации (поверх основной) | дыхание поверх ходьбы | L |
| Один HTML-файл экспорта (плеер + скелет + атлас) | отправить заказчику одним файлом | M |
| Контрольные точки (checkpoints) со сравнением | «до / после» по правке | M |
| Отладка констрейнтов: показать, какая кость что тянет | у Spine нет | M |
| Разбить анимацию на несколько по отметкам (из roadmap) | одна длинная запись → набор клипов | M |
| Импорт GIF или листа спрайтов (sprite sheet) как последовательности | нарисованные покадровые эффекты чаще лежат листом или GIF, чем папкой пронумерованных файлов | M |
| Перетащить папку пронумерованных картинок и сразу получить последовательность | сейчас: импорт картинок, потом «Сделать последовательность» | S |
| Предпросмотр последовательности на таймлайне (миниатюры кадров) | видно, какой кадр где | M |
| Linked mesh как настоящая связь (общая геометрия, свои текстуры) | скины с разными текстурами на одной сетке без копий | L |
