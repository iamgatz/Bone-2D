# Bone 2D

[English](README.md) · **Русский**

Открытый браузерный редактор 2D-скелетной анимации (в духе Spine). Экспорт — в формат **Spine 4.3** (`.json` + `.atlas` + `.png`);
в тестах экспорт сверяется с официальным рантаймом `spine-core` 4.3.

**[Открыть редактор →](https://iamgatz.github.io/Bone-2D/)** — ничего ставить не нужно, всё работает локально в браузере.
Интерфейс — на **русском и английском** (переключатель в верхней панели; выбор запоминается, при первом заходе берётся язык браузера).

```bash
npm install
npm run dev        # http://localhost:5273
npm test           # unit-тесты + случайные сессии редактора, включая сравнение с официальным spine-core 4.3
npm run build      # production-сборка в dist/
```

Длинный прогон случайных сессий (`FUZZ_FROM` — с какого seed начать):

```bash
FUZZ_SEEDS=300 FUZZ_STEPS=100 npx vitest run tests/fuzz.test.ts
```

```powershell
$env:FUZZ_SEEDS='300'; $env:FUZZ_STEPS='100'; npx vitest run tests/fuzz.test.ts
```

## Что умеет

**Риггинг (режим Setup)**
- Кости: создание перетаскиванием (цепочки от кончика выбранной кости), иерархия с drag-and-drop, режимы наследования (`normal`, `onlyTranslation`, `noRotationOrReflection`, `noScale`, `noScaleOrReflection`).
- **Импорт из Photoshop**: перетащите `.psd` в окно (или в окно «Картинки») — каждый видимый слой станет картинкой и слотом с регионом, нижний слой первым, так что стопка слоёв файла становится порядком отрисовки. Группы превращаются в папки, прозрачность и режимы наложения multiply / screen / additive сохраняются, скрытые слои пропускаются; один Undo возвращает всё. Начало координат — середина нижней кромки документа (маски, обтравочные слои и эффекты не применяются). **Обновление из PSD** (кнопка в окне «Картинки») сопоставляет слои перерисованного файла с картинками по имени: новые пиксели, вложения следуют за размером и сдвигом слоя, новые слои становятся слотами, риг остаётся.
- Слоты и картинки: перетаскивание PNG в окно, порядок отрисовки, blend-режимы, tint и **two-color tint** (тёмный цвет проступает там, где картинка тёмная: свечение, вспышка при ударе; в режиме Animate ключуется вместе со светлым).
- **Меши**: автотрассировка по альфе → Delaunay-триангуляция, правка вершин, добавление/удаление, ретриангуляция.
- **Веса**: привязка к костям (auto-weights), кисть (add / subtract / replace / smooth), heat-map, нормализация, до 4 влияний на вершину.
- **IK** (1 и 2 кости): mix, softness, bend, stretch, compress, scaleY-режимы; создание перетаскиванием.
- **Transform-констрейнты 4.3**: маппинг любого свойства источника на любое свойство цели, clamp, local/world, additive, пресеты.
- **Слайдеры 4.3**: применяют выбранную анимацию с ручным временем (его и mix можно ключевать) или со временем от свойства кости
  (`время = to + (значение − from) × scale`, local/world, loop, additive). Создаются кнопкой «+» у списка Constraints.
- **Clipping, bounding box, point** (инструменты `C` / `X` / `P`): полигон кликами (замыкание — клик по первой точке, двойной клик или Enter), правка вершин
  (перетаскивание, Ctrl-клик по ребру добавляет, Del удаляет), `end`-слот, `convex` / `inverse`. Клиппинг рисуется stencil-буфером по семантике Spine
  (конечный слот клипуется включительно); импортированные взвешенные полигоны сохраняются и рисуются.
- **Пути** (инструмент `N`): path-аттачменты — кривые Безье; клик ставит узел, перетаскивание вытягивает рычаги; узлы правятся инструментом меша (`M`), Ctrl-клик / двойной клик по кривой добавляет узел, `Del` удаляет. Замкнутый / разомкнутый, постоянная скорость или длины из позы настройки, привязка к костям с автоматическими весами.
- **Path-констрейнты 4.3** (кнопка со сплайном у списка Constraints): выбранные кости следуют за путём, который показывает слот — режимы поворота `tangent` / `chain` / `chainScale`, позиции `fixed` / `percent`, интервала `length` / `fixed` / `percent` / `proportional`, смещение поворота, три микса.
- **Physics-констрейнты** (Spine 4.2+; кнопка с волной у списка Constraints): пружинная симуляция одной кости — качается (rotate), сдвигается (x / y), растягивается (scale X, режимы scale Y `none` / `uniform` / `volume`) или скашивается — с инерцией, силой, затуханием, массой, ветром, гравитацией, mix, пределом и собственным шагом. Симуляция идёт, пока играет анимация (при перемотке показывается поза без неё); любой параметр можно ключевать, поддержаны глобальные таймлайны и ключи сброса.
- Скины (подмена картинки в слоте), события, undo/redo (жесты схлопываются в один шаг).

**Рабочее место**
- **Папки с картинками**: перетащите папку в окно «Картинки» или во вьюпорт (или нажмите кнопку с папкой); вложенные папки остаются папками картинок (`hero/arm/upper`), один Undo возвращает всё.
- **Назначить родителя** (`Shift+P`): выберите кости или слот и кликните новую родительскую кость во вьюпорте или в дереве; кости остаются на месте, один Undo.
- **Разрезать кость** (панель кости, раздел «Разрезать»): кость делится на 2–32 коротких, цепочкой или рядом, поровну или по Фибоначчи; дочерние кости на дальнем конце переходят на последнюю часть, один Undo.
- **Веса**: Авто, Сглаживание и Очистка работают только на выбранных вершинах (или на всей сетке), у Очистки есть лимит костей и порог, Обмен меняет веса двух костей, «Обновить привязку» освежает позу привязки после сдвига костей, «Слить» берёт веса другой сетки там, где они перекрываются, «Круги» / «Заливка» / «Выбранные» показывают веса на сетке, список костей с цветами и «Убрать», Замок сохраняет веса кости при рисовании, у кисти есть Растушёвка, веса копируются и вставляются между вершинами.
- **Меню «Окна»**: Иерархия, Картинки, Анимации, Сводка, Инспектор и Таймлайн открываются и закрываются по отдельности, готовые раскладки, `F9` прячет всё; расположение запоминается. «Сводка» считает кости, меши, вершины и ключи и показывает, что похоже на забытое перед экспортом.
- **Настройки** (`F12`): язык, автосохранение, фон вьюпорта, сглаживание текстур, зум в курсор, кадры onion skin, а **буквы инструментов** можно менять.
- **Обновления** (колокольчик) показывают, что нового, и живую ленту активности проекта; **Обратная связь** — сообщить об ошибке или идее.
- Инструменты: выбор / поза, кости, перенос, поворот, масштаб, **shear** (`H`), меш, веса, IK, clipping, bounding box, точки, пути. Меню «Правка»: **дублирование и зеркальная копия костей** (с детьми, слотами и картинками), сброс / копирование / вставка позы.

**Анимация (режим Animate)**
- Автоключ (или ручные ключи + «Key all»), ключи для rotate / translate / scale / shear, цвета слота (светлый и тёмный), смены attachment, IK mix/bend, миксы transform-констрейнтов, **позиция / интервал / миксы path-констрейнтов**, **деформации мешей и путей** (в режиме Animate тяни узлы), порядок отрисовки, события.
- Dopesheet: выделение, рамка, перетаскивание ключей с привязкой к кадрам, копирование/вставка, интерполяция (linear / stepped / bezier / ease).
- **Graph editor**: кривые по каналам, перетаскивание ключей и ручек Безье.
- Окно **«Инструменты анимации»**: *Упрощение ключей* убирает ключи, которые кривой не нужны (допуск меняется, заранее видно, сколько уйдёт), *Запечь констрейнты* записывает работу IK, transform, path, физики и слайдеров в обычные ключи костей новой анимации (каждый кадр или каждый N-й, с упрощением по желанию, констрейнты в копии выключены). Сверено кадр за кадром с оригиналом в тестах со случайными сессиями.
- **Горячие клавиши**: сочетание любой команды можно поменять в «Настройки → Горячие клавиши» (не только буквы инструментов); совпадение с другой командой, инструментом или браузером не принимается, с названием того, чем занято.
- Окно **«Позы»**: библиотека поз с именами; клик накладывает позу на выбранные кости (позу по умолчанию в режиме Setup, ключи в точке маркера в режиме Animate), можно лишь частично. Хранится в файле проекта, в экспорт не попадает.
- **Фильтр иерархии** по имени, **Ctrl+H** показывает всё скрытое, **Ctrl+Shift+H** показывает только выбранное.
- **Замкнуть петлю**: конец анимации получает значение начала, для бесшовных циклов.
- **Последовательности** (покадровые картинки на регионе или меше) со всеми семью режимами Spine: в редакторе, экспорте JSON / бинарном и импорте.
- **Linked mesh**: скин даёт сетке другую картинку и сохраняет её форму, веса и деформацию; связь пишется в файлы Spine и читается из них.
- **Звуки событий** (путь, громкость, баланс) правятся в иерархии и сохраняются в экспорте и импорте Spine.
- **Линейки, направляющие и привязка** к сетке и направляющим (направляющие сохраняются в проекте).
- Скопированные ключи одной кости **вставляются на выбранную кость**; в настройках: толщина костей и подсказки.
- **Упаковщик текстур**: обрезка пустоты, поворот, фильтр Linear / Nearest, отступ, степень двойки, размер страницы; настройки экспорта запоминаются и сохраняются в файл / загружаются из файла.
- Воспроизведение, loop, шаг по кадрам. **Onion skin** (бледные позы до и после маркера), **Clean Up** (убирает ключи, которые ничего не меняют), **Alt-перетаскивание ключа** сдвигает и ключи после него, окно «Анимации» с папками (`emotes/wave`).

**Файлы**
- Проект `.bone2d` (картинки внутри), автосохранение в IndexedDB, File System Access API (Ctrl+S сохраняет в тот же файл, Ctrl+Shift+S спрашивает куда; в окне приветствия список недавних проектов). Старые файлы `.marrow` (прежнее рабочее имя проекта) по-прежнему открываются.
  При открытии файл **проверяется и чинится** (битые ссылки, устаревшие ключи деформации, NaN, дубли имён); повреждённая картинка не стирает открытую сессию.
- Экспорт ZIP: Spine 4.3 JSON **или бинарный `.skel`** (примерно вдвое меньше) + атлас (MaxRects, экструзия краёв) + `*-preview.html` (играет экспорт **официальным** плеером Spine); можно выбрать, какие анимации попадут в экспорт, размер страниц, отступ, степень двойки.
- **Отрисовать анимацию в GIF** (с прозрачностью, свой кодировщик), **последовательность PNG** (ZIP) или **видео WebM** — Файл → Экспорт → вкладка «Анимация».
- **Импорт Spine: JSON 4.0 – 4.3 и бинарный `.skel` 4.3** (File → Import…): выбери `.json` / `.skel` вместе с `.atlas` и картинками страниц — регионы нарезаются (с учётом
  trim-offsets и поворота). Файлы Spine 4.0 / 4.1 / 4.2 (отдельные списки `ik` / `transform` / `path`, старая модель transform-констрейнта) по пути переводятся в модель 4.3;
  два случая, где 4.3 считает transform-констрейнт иначе, чем 4.2, перечисляются. Не поддерживаемое (sequences …) пропускается и перечисляется в консоли.
  Экспорт → импорт → экспорт даёт тот же JSON байт в байт.

## Почему экспорту можно доверять

`tests/spine-parity.test.ts` экспортирует «злой» тестовый риг (все режимы наследования, shear, IK, 4 transform-констрейнта,
взвешенные и обычные меши, деформации, цвета, события, скины, случайные порядки отрисовки; `tests/path.test.ts` добавляет открытые / замкнутые / взвешенные пути и path-констрейнты во всех режимах, а `tests/physics.test.ts` играет physics-констрейнты кадр за кадром против того же рантайма), загружает JSON официальным
`@esotericsoftware/spine-core@4.3.x` и сравнивает **мировые матрицы всех костей, вершины мешей, цвета, attachment’ы и порядок
отрисовки** с нашим собственным солвером в десятках моментов времени. Проверка не пустая: тесты-«мутанты» подтверждают, что
любое расхождение ловится. Clipping, bounding box и point проверяются так же, включая настоящие `SkeletonClipping` и `SkeletonBounds` (`tests/attachments.test.ts`).

Второй уровень доверия — **случайные сессии** (`tests/fuzz.test.ts`): сотни последовательностей настоящих действий редактора
(кости, меши, веса, IK, transform-констрейнты, слайдеры, ключи, undo/redo …). После **каждого** шага документ не должен требовать
починки, экспорт должен грузиться официальным рантаймом, матрицы — быть конечными; в конце наш солвер сверяется с официальным,
«undo всё» возвращает исходный документ, «redo всё» — итоговый. Так найдены и исправлены ошибки порядка обновления
(модель 4.3 с ленивыми `world/local`), float32-π Spine, потеря ключей деформации при правке мешей и др. (см. `docs/ROUND2.md`).

## Устройство

```
src/core      чистая логика без DOM: модель, кривые (та же 10-сегментная аппроксимация, что в рантайме),
              skeleton.ts (pose, inherit-режимы, IK, transform-констрейнты, слайдеры, скиннинг), animate.ts, mesh.ts,
              clip.ts (план клиппинга), validate.ts (проверка/починка документа), export/ (spineJson, atlas, zip), import/ (spineJson, atlas)
src/store     document store на immer-патчах (undo/redo), UI-стор, actions
src/render    WebGL2-рендерер (батчи, blend-режимы, тинт, stencil-клиппинг)
src/editor    React-панели, viewport (Canvas2D-оверлей + инструменты), dopesheet, graph editor
tests         vitest: ядро, меши/веса, дифф-тесты против официального рантайма, случайные сессии
docs          заметки и планы (PROMPT.md — самопромпт, RESEARCH.md — формат 4.3, PLAN.md, ROUND2/3.md)
```

Стек: TypeScript (strict), Vite, React 19, immer, delaunator, собственный WebGL2-рендерер.
Подробности и обоснование выбора — в [docs/PROMPT.md](docs/PROMPT.md); формат 4.3 — в [docs/RESEARCH.md](docs/RESEARCH.md).

## Горячие клавиши

`V` выбор/поза · `B` кость · `T` `R` `S` перенос/поворот/масштаб · `M` меш / узлы пути · `W` веса · `I` IK · `C` clipping · `X` bounding box · `P` point · `N` путь · `H` shear · `Tab` Setup⇄Animate ·
`Space` плей · `←/→` кадр · `K` ключ · `Ctrl+Z/Y` undo/redo · `Del` удалить · `F` показать скелет · `Ctrl+S/O/E` сохранить/открыть/экспорт · `Ctrl+D` / `Ctrl+Shift+D` дублировать / отразить кости · `F9` скрыть окна · `F12` настройки.

## Не сделано (следующие шаги)

веса и деформации для clipping / bounding box (правка — только перенос вершин), 
sequence-атласы, draw-order folders, бинарные файлы Spine 4.0 – 4.2,
совместная работа.

Известные особенности Spine, которые мы повторяем намеренно: углы переводятся через float32-π (`180 / 3.1415927`), а чтение
мирового поворота на границе 0/360° (источник transform-констрейнта или драйвер слайдера) даёт 0 или 360 в зависимости от
шума ~1e-6°, поэтому разные рантаймы могут разойтись на таком ребре.

## Участие в разработке

Issues и pull request’ы приветствуются. Страховка — тесты, запускай их перед отправкой изменений:

```bash
npm test
npm run build
```

Новая возможность редактора считается законченной, когда прошла всю цепочку: модель → валидатор → солвер/рантайм → экспорт → импорт → дифф-тест против официального
рантайма → UI → операция в наборе случайных сессий (`tests/fuzzkit.ts`). Обоснование — в `docs/ROUND3.md`.

Тексты интерфейса в компонентах остаются английскими и переводятся при отрисовке (`src/i18n`): русский вариант любой новой строки добавляй в `src/i18n/ru.ts`
(`{}` в ключе — любой текст, `{#}` — число). `npm test` падает, если у статической строки интерфейса нет перевода. Чтобы добавить другой язык, заведи словарь по образцу `ru.ts` и расширь `Lang`.
